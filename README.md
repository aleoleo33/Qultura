# Qultura
Art community and marketplace platform built with Expo and React Native.

## Features
- **Curated Home Feed:** Masonry grid of fresh artworks from independent creators.
- **Marketplace & Auctions:** Collect artworks, bid on live auctions, and browse commission opportunities.
- **Creative Circles & Community:** Discover local and online art communities, events, and mentorship.
- **Creator Studio:** Share your creative process, publish new posts, and showcase your portfolio.

## Get started

1. Install dependencies
   ```bash
   npm install
   ```

2. Start the app
   ```bash
   npx expo start
   ```

In the output, you'll find options to open the app in:
- Android emulator / device
- iOS simulator / device
- Web browser (`w`)
- Expo Go
